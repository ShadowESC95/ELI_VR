# ELI VR 0.9.22 — ELI's world arrives in small messages

**ELI's world** no longer comes whole every time anything in it changes. ELI VR now keeps the records it was sent (ELI's books, what it holds about you, its memories), and ELI v3 sends a record in full only when it is new or has changed; one that is the same comes by its id alone. With a full house of books a repeat message is about a twelfth of the size it was, so there is far less to read each time ELI moves or thinks.

Needs ELI v3 3.0.165 or later for the smaller messages; with an older ELI v3 everything works as before, whole messages each time. Not yet checked in a headset: the sizes were measured headless with a large invented message, not real data.
