# ELI VR 0.9.21 — the Evidence Wall no longer holds the headset up

**The Evidence Wall** works its boards out again only when its own part of ELI's message changed. Before, every message from ELI made it redo all of them, whatever had changed, which cost two or three frames each time. Walking into the room is quicker too: a record is laid out on a sheet only where it could fit, instead of being tried in full on every sheet of the wall. The wall looks the same: the same sheets in the same places at the same sizes.

Works with ELI v3 3.0.163 or later. Not yet checked in a headset: the times were measured headless with a large invented message, not real data.
