# ELI VR 0.9.26 — licensing as every ELI product

- **A seven-day trial from first use**, as ELI v3, ELI Legal and ELI Creation Station give. Deleting its records, editing them or setting the clock back does not restart it.
- **A bought key works on as many computers as it has seats.** A key bought from the licence store from now on is activated once, the first time it is entered on a computer: ELI VR sends the key and the computer's activation code (a one-way code made from the operating system's install id) to ELI's licence server, which counts the computer against the licence's seats. After that it is checked on your computer. **0.9.25 and earlier cannot activate these keys: update to 0.9.26.** Keys issued before keep working.
- **Keys bought from the licence store are read** (earlier releases refused them), and a key made for one computer opens nothing on another. Withdrawn licences stop working.
- **The control dock's Licence…** shows the licence, this computer's activation code (with Copy, for activating from another device at https://licences.geteli.tech/activate when this one cannot go online), and **Deactivate this computer**, which gives the seat back so the licence can move to another computer.
- When online, ELI VR fetches the list of withdrawn licences at launch and, during the trial, asks for this computer's trial. Nothing else is sent.
- Only an ELI VR key, or an ELI v3 key sold with ELI VR included, opens ELI VR.
