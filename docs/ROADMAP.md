# Roadmap

Where ELI VR is, and what comes next. Dates are not promised.

## Done

- One project for Linux, Windows and macOS, in a headset through OpenXR or flat on a monitor
- Fifteen places, each its own built scene with real skies, scanned materials and things that move
- Eight themes, four quality profiles
- Spatial console, wrist menu, portals, grab and move panels and objects, free flight
- Live desktop screen through a capture helper on each OS
- The link to ELI v3: his presence in the rooms, push to talk, his voice
- ELI VR as an ELI v3 bundle: ELI v3 lists it and opens it
- Release builds for the three systems and a Linux AppImage, with a clean stop of the VR runtime on exit
- A privacy gate on everything published

## Next

- ELI's world objects drawn in the rooms (they already arrive)
- ELI as a figure, not a light
- ELI building and changing rooms himself
- Pointer and keyboard through the desktop screen, not view only
- The Windows and macOS builds run on real machines, and the other controllers on real hardware
- The old generated room code and its textures removed

## Later

- Shared-texture desktop capture per OS, in place of JPEG frames
- Hand tracking where the runtime has it
- A native build for standalone headsets
- Signed and notarised builds
- Room packs made by other people, installed from a local file
- Licence editions in ELI v3 deciding which bundles open
