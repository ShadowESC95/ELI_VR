# Roadmap

- OpenXR + flat fallback
- 15 procedural environments
- symbolic rooms + portals
- themes
- quality profiles
- spatial console
- local settings dock
- XR pointer interaction
- locomotion
- live desktop fallback bridge source

- standalone Android OpenXR package
- remote ELI bridge
- account/profile sync
- downloadable room/theme packs

## 1.0

- ELI v3 integration
- stable platform capability matrix
- signed installers/export builds
- migration/versioning for user worlds
